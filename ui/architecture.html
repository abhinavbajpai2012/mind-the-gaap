We did not invent a method. We took the way an equity analyst actually forecasts — split the business into categories, read what each did last quarter, read what management said about next quarter, judge each part forward — and rebuilt it so it runs over 1,139 documents instead of a handful, and so that every number carries the file and line it came from.

How an analyst does it How our agent does it Interchange — same job, more breadth

Gather the filings

Opens the last few quarterly reports, the earnings call transcript and the results deck. Realistically: a handful of documents, the ones he already knows.

Index the whole corpus

All 1,139 documents classified from their filenames, then each one's fiscal period resolved from ranked evidence. The corpus's own period: field is read but never trusted — it labels ADI's Q2 10-Q as "Q3 2026".

Split the business into categories

Decides the product or segment breakdown — what the range is, which lines carry the revenue, which matter to the story.

2
Live

Discover the split from the tables

Segments are read off the corner cell of the company's own segment tables, not configured by us. Deere's filings yield Production & Precision Agriculture, Small Agriculture & Turf, Construction & Forestry — each row separately addressable.

Read last quarter's performance

Pulls the actuals off the results tables and the slides, and builds a history to extrapolate from.

3
Live

Extract cited actuals

Markdown tables parsed so that the period belongs to the column, not the document. Every figure returns as value · period · file:line. Ask any number .why() and it lists what it accepted and what it refused.

Read management guidance

The outlook section and the call: what the company says about the quarter that has not happened yet. This is where most of the signal is.

4
Live

Retrieve guidance deterministically

Next quarter's guidance lives in this quarter's 8-K and call, so retrieval is period-aware by design: docs("ADI","FY2026Q2",kind="transcript") is how you reach the Q3 outlook.

Decide what drives what

Knows from experience which drivers move which line — footfall to comparable sales, order book to revenue — and weights them by judgement.

5
Next

Feature selection over extracted CSVs

The corpus is reduced to quantifiable fields — actuals, guidance, operational drivers, segment mix. A model then selects which columns predict which target, rather than a human asserting it. Extraction is done; selection is the next build.

Judge each category forward

Applies growth to each category and sums to a number. One method, one analyst, one opinion.

6
Live

Forecast, then backtest the method

Today: seasonal year-on-year — anchor on the same period a year earlier, grow by the company's own recent rate. Seasonality is not optional; Home Depot's Q2 is its spring peak. Next: several models scored against held-out quarters, best one wins.

Adjust for tone and macro

Nudges the number if the call felt defensive, or if the macro backdrop turned. Real skill, entirely unrecorded.

7
Live

Quantify tone, and cap it

A call-tone subagent scores the Q&A against the company's own prior calls, not an absolute scale, and returns ordinal channels. It enters as a capped tilt — 3%, or 0.5pp on a rate — because tone should move a forecast, never drive it.

Where the machine goes past the analyst

Breadth

An analyst reads the documents he already trusts. The agent reads every document for a company and keeps only what survives a period filter — then tells you what it threw away and why.

Defensibility

A pipeline cannot contribute a number without citations — push() raises Undefensible if you try. The run log is not written for the judges; it is a by-product of the design.

Generality

Nothing about these four companies is compiled in. A new company is Profiler.fit(dir), which derives its fiscal calendar and self-certifies. A new metric is one entry in a JSON file.

Refusal

When the evidence does not support an answer, it raises instead of guessing — and names the corrected call. Hays has no Q2, so asking for one gets you a pointer to H1, not a plausible fabrication.

Traps this exists to survive · all measured in this corpus

TrapWhat it does to a naive reader
Metadata is wrongThe corpus labels ADI's Q2 FY2026 10-Q as "Q3 2026". Filtering on it drops the single most important document.
Year-to-date columnsADI's Q3 10-Q holds 74 "Nine Months Ended" headers beside 70 "Three Months". Taking the wrong one is a ~3× error.
Prior-year comparativesLast year's column sits directly beside this year's in every results table.
Scale captions(in thousands) appears 459× against output cells denominated in millions — a 1000× error.
Pence, not poundsHays quotes EPS as 1.31p. Read as £1.31 that is a 100× error, and (0.49)p is negative.
Fiscal year offsetsHome Depot's February Q4 belongs to the previous fiscal year. Only one of the four does this.
Identical row labelsDeere prints "Diluted" twice in one table: 4.75 (EPS) and 271.4 (share count). Only the section header separates them.
Unlabelled segmentsThree Deere segments each label their row merely "Operating profit" — 580 / 485 / 237. The segment name is in the table's corner cell.

One command

Run it

python3 main.py --cli --audit — headless, prints the table and writes the run log.

Stack

Aggregator is standard-library Python, no dependencies. Signal subagents use pydantic. No network calls at run time — the corpus is frozen and local.

Honest gaps

The model layer is a seasonal baseline, not yet a scored ensemble. Hays' forecast does not yet use its already-reported H1. Both are named, not hidden.
